# 論文進度 Dashboard 設計規格

## 目標

建立一個公開、安全、可由 GitHub Pages 託管的單頁儀表板，讓使用者快速理解論文目前階段、章節進度、近期工作、阻塞事項與重要研究決策。

## 已確認方向

- 採「研究指揮台」作為首頁資訊架構，加入研究摘要敘事與里程碑時間軸。
- 提供「個人管理」與「教授簡報」兩種顯示模式。
- 採半自動更新：人工維護 `data/status.json`，建置程式驗證並產生自包含 `dist/index.html`。
- 建立獨立公開 GitHub repository，私有論文 repository 不作為 Pages 來源。
- 不公開姓名、學校、實驗室、教授、Notion 連結、私人 repository、本機路徑或實驗 raw data。

## 資料來源與口徑

更新資料時依序參考主論文 repository 的 `WORK_SPLIT.md`、`PROJECT_MEMORY.md`、`THESIS_OUTLINE.md` 與 `EXPERIMENT_ARCHITECTURE.md`。若狀態互相衝突，以更新日期較新且對該主題具所有權的文件為準。Dashboard 顯示的是人工維護的規劃快照，不宣稱為即時自動分析。

整體進度使用六類加權里程碑：研究設計 20%、文獻回顧 15%、實驗環境與程式 20%、Pilot 與正式實驗 25%、論文撰寫 15%、口試與提交 5%。每類完成率由具體交付物判定，首頁清楚標示「人工維護的加權規劃進度」。

## 介面

- 首屏：論文短標題、目前階段、加權進度環、下一個關卡、最近更新時間。
- 摘要指標：完成章節、文獻數、Pilot episodes、待處理阻塞。
- 進度區：六類里程碑橫條及八章狀態。
- 行動區：本週重點、下一步、等待使用者或實驗主機的事項。
- 研究架構：兩類攻擊、L1–L3 三層防禦與模擬執行器流程。
- 決策時間軸：只呈現可公開且已定案的重要決策。
- 教授模式隱藏細部技術待辦，保留研究問題、進度、成果與風險。

視覺採深藍灰底、青藍重點色、克制的卡片層級與內嵌 SVG 圖示。頁面支援手機、鍵盤操作、減少動態效果偏好及列印時的淺色一頁式摘要。

## 技術架構

- `data/status.json`：唯一公開進度資料來源。
- `src/template.html`：完整 HTML、CSS、JavaScript 與 SVG 圖示，不連接外部 CDN。
- `scripts/build.mjs`：驗證資料、計算加權進度、將 JSON 安全嵌入模板並輸出 `dist/index.html`。
- `tests/dashboard.test.mjs`：驗證權重、必要欄位、敏感內容規則、產出完整性與零外部網路依賴。
- `.github/workflows/pages.yml`：push 至 `main` 時建置、測試並部署 GitHub Pages。

## 錯誤處理與驗收

資料缺欄、權重不是 100、完成率超界、出現禁止公開字串或模板標記未替換時，建置必須失敗。完成版需通過 Node 測試、成功產生單一自包含 HTML，並在桌面與窄螢幕檢查無水平溢位。
